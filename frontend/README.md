# Frontend — Web Chat

Interface web do [Web Chat](../README.md), em Next.js 16 (App Router), TypeScript e Tailwind.

```bash
npm install
npm run dev            # http://localhost:3000, contra o backend em :8080
npm run build          # gera frontend/out, que o Maven empacota dentro do jar
```

A documentação do módulo — estrutura, autenticação, tempo real e decisões — está em
[docs/frontend.md](../docs/frontend.md).

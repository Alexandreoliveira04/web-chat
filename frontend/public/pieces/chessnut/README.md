# Peças de xadrez — Chessnut

Peças usadas no tabuleiro de xadrez (`components/games/ChessBoard.tsx`).

- **Autor:** [Alexis Luengas](https://github.com/LexLuengas) — <https://github.com/LexLuengas/chessnut-pieces>
- **Licença:** Apache 2.0 (texto completo em [LICENSE.txt](LICENSE.txt))
- **Origem dos arquivos:** cópia sem alterações de `public/piece/chessnut` do
  [lichess](https://github.com/lichess-org/lila), que distribui o mesmo conjunto.

Nomes: `w`/`b` (brancas/pretas) + `K` rei, `Q` dama, `R` torre, `B` bispo, `N` cavalo, `P` peão.
